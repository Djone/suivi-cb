## Prochaine étape NAS

Le NAS dispose de 331 Mo disponibles au contrôle transmis par l'utilisateur.
Seule la production est active ; aucune préproduction n'apparaît dans sa liste.
L'accès SSH direct depuis l'agent expire : les opérations NAS passent par la
session SSH de l'utilisateur.

1. Copier le dossier local du package vers `/volume1/docker/2.2.0-rc.6` avec File
   Station. Vérifier `SHA256SUMS` et `EVIDENCE-SHA256SUMS` avant tout import.
2. Préparer une pile de recette privée avec une copie vérifiée d'une sauvegarde
   SQLite ; conserver les données de production et les services Keycloak actifs.
   Appliquer `nas-limits.yml` et utiliser le realm `suivi-cb-preprod`.
3. Le Compose livré publie seulement `127.0.0.1:4201`. Vérifier la destination du
   proxy DSM préproduction avant le parcours navigateur : l'ancienne référence
   utilisait 4203. Garder son ACL LAN. Aucun port backend ne doit être publié.
4. Recette réelle Keycloak/Angular, métier et rollback sur les images exactes.
   Puis rétention/surveillance des sauvegardes, protections GitHub et droits NAS,
   rapport d'approbation et MEP supervisée.
